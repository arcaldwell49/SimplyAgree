# Test fixtures

`ox.rds` and `fat.rds` are the `ox` and `fat` data sets from the MethComp
package (version 1.30.0, archived on CRAN; Bendix Carstensen et al.,
GPL (>= 2)), saved unchanged with `saveRDS()`. They are used only to check
`method_vc()` against the results in Carstensen (2010), *Comparing Clinical
Measurement Methods: A Practical Guide*, Wiley, and MethComp's `BA.est()`.
